B. API / DATI ORIGINE
================================================================================

API PRIMARIA: Open-Meteo (gratuita, no API key)
--------------------------------------------------------------------------------
- Endpoint: https://api.open-meteo.com/v1/forecast (via proxy locale /api/open-meteo)
- Modello: GFS / AROME / ICON (scelto automaticamente da Open-Meteo per l'Europa)
- Periodicità: Oraria, fino a 120 ore (5 giorni)
- Auto-refresh: ogni 15 minuti

PARAMETRI RICHIESTI (HOURLY_PARAMS in weatherService.ts):
--------------------------------------------------------------------------------
temperature_2m, relative_humidity_2m, dew_point_2m, apparent_temperature,
precipitation, precipitation_probability, weather_code, pressure_msl, surface_pressure,
cloud_cover, cloud_cover_low, cloud_cover_mid, cloud_cover_high,
wind_speed_10m, wind_direction_10m, wind_gusts_10m,
uv_index, shortwave_radiation, direct_radiation, sunshine_duration,
temperature_80m, temperature_120m,
wind_speed_80m, wind_direction_80m,
wind_speed_120m, wind_direction_120m,
wind_speed_180m, wind_direction_180m,
cape, convective_inhibition, lifted_index,
freezing_level_height,
wind_speed_925hPa, wind_direction_925hPa,
wind_speed_850hPa, wind_direction_850hPa,
wind_speed_700hPa, wind_direction_700hPa,
wind_speed_600hPa, wind_direction_600hPa,
wind_speed_500hPa, wind_direction_500hPa

API SECONDARIA: Tomorrow.io (opzionale, serve VITE_TOMORROW_KEY)
--------------------------------------------------------------------------------
- Usata da: TomorrowWindgram.tsx, WindgramPro.tsx, TomorrowrowWindgram.tsx
- Campi: windSpeed, windDirection, temperature, cloudCover, dewPoint a 10 livelli
- SEPARATA dall'API primaria — dati potentially diversi

FALLBACK OFFLINE: fallbackWeatherData.ts
--------------------------------------------------------------------------------
- Genera dati realistici ma NON reali basati su fisica approssimata
- Attivato solo quando l'API fallisce

================================================================================
E. DATI VERTICALI DISPONIBILI — LIMITAZIONI REALI
================================================================================

✅ DISPONIBILI (dati reali API)
--------------------------------------------------------------------------------
Quote vento: 10m, 80m, 120m, 180m, 925hPa(760m), 850hPa(1450m),
            700hPa(3000m), 600hPa(4200m), 500hPa(5500m)
Quote temperatura: 2m, 80m, 120m, 180m
Temperature a livelli isobarici: solo in AlpiumWindgram (500-1000hPa)
Zero termico: dato reale API (freezing_level_height)

⚠️ DERIVATI / STIMATI (calcolati dal codice)
--------------------------------------------------------------------------------
DeltaT / lapse rate:    calcolato come (t2m - t180m) / 180 * 100,
                        oppure stimato con modello sinusoidale se dati mancanti
Base cumuli (LCL):      altitude + (T - Td) * 125 — formula standard
Top termica:            stimato come cloudBase + rateo * 100 + cape * 0.1
Rateo termica:          formula basata su spread + radiazione + CAPE
Boundary Layer:         non c'è dato reale; stimato o disattivato
Shear:                  non calcolato esplicitamente in nessun windgram

❌ NON DISPONIBILI (manca nell'API gratuita)
--------------------------------------------------------------------------------
Umidità relativa in quota              ❌ Non chiesta, non disponibile
Venti ai livelli intermedi             ❌ Non disponibili (es. 875, 750, 650, 550 hPa)
Temperature ai livelli intermedi       ❌ Solo in AlpiumWindgram
Dati radiosondaggio reali              ❌ Non disponibili (servirebbe API a pagamento)
Shear verticale calcolato              ❌ Non presente in alcun componente
Convergenza                            ❌ Assente
Top boundary layer reale               ❌ Stimato, non misurato
Velocità media termiche reale          ❌ Stimata da formula empirica
