2. src/utils/windShearCalculator.ts (NUOVO)
--------------------------------------------------------------------------------
Calcolo puro dello shear verticale:

```typescript
export function directionDifference(a: number, b: number): number {
  // Gestisce correttamente 359° → 0° = 1°, non 359°
  let diff = Math.abs(((a % 360) + 360) % 360 - ((b % 360) + 360) % 360);
  if (diff > 180) diff = 360 - diff;
  return diff;
}

export interface WindShearResult {
  lowerAltitude: number;
  upperAltitude: number;
  lowerSpeed: number;
  upperSpeed: number;
  lowerDirection: number;
  upperDirection: number;
  speedDifference: number;        // km/h
  directionDifference: number;    // gradi, 0-180
  speedDifferencePer100m: number;
}
```

NESSUNA classificazione di rischio ("alto"/"medio"/"basso") — solo dati quantitativi.
