File: src/utils/windShearCalculator.ts

1. directionDifference(a, b)
   - Differenza angolare più breve (0–180°)
   - Formula: Math.abs(((a%360+360)%360 - (b%360+360)%360)); se >180 allora 360-diff
   - ✅ Gestisce correttamente 359°→0°

2. calculateWindShear(lower, upper)
   - speedDifference: valore assoluto km/h
   - directionDifference: gradi, 0–180° (percorso più breve)
   - speedDifferencePer100m: speedDiff / altDiff * 100
   - Unità: km/h per 100m di dislivello
   - ❌ Non calcola shear vettoriale
   - ❌ Non calcola rotazione del vento

3. calculateShearProfile(observations)
   - Ordina per altitudine crescente
   - Calcola shear tra coppie adiacenti
   - Skippa coppie con dati mancanti

Nel contesto di derivedMeteorology.ts:
- buildVerticalWindProfile calcola shear tra: ground(sito) → 925hPa → 850hPa → 700hPa → 600hPa → 500hPa
- Le quote usate sono ISA stimate (760, 1450, 3000, 4200, 5500)
- Il vento è REALE dall'API (se disponibile)

B. GRANDEZZE DERIVATE DA DATI REALI
─────────────────────────────────────
Spread (T-Td)          = max(0.5, temperature2m - dewPoint2m)
Cloud Base (LCL)       = siteAlt + min(1800, spread * 125), min gain 100m
Real Lapse Rate        = (T2m - T80m) / 78 * 100  OPPURE (T2m - T120m) / 118 * 100
Lapse Rate Classification = <0=inversione, <0.3=stabile, <0.65=neutro, <0.98=instabile, ≥0.98=molto_instabile
Wind Shear (velocità)  = |speed_upper - speed_lower|
Wind Shear (direzione) = directionDifference(dir_lower, dir_upper)
Wind Shear (per 100m)  = speedDiff / altDiff * 100
Wave Index             = directionDifference(dir10m, dir850hPa)

C. STIMA EMPIRICA DEL PROGETTO
─────────────────────────────────────
Estimated Thermal Top         = cloudBase + min(800, CAPE*0.1) + spread*50, max 5000m
Rateo Termico (indiceVolabi)  = max(0, spread*0.22 + min(1.5, CAPE/800))
Rateo Termico (expertoMeteo)  = min(4.0, max(0.3, avgSpread*0.25 + avgCape*0.001))
Thermal Top (expertoMeteo)    = min(4000, cloudBase + min(800, rateo*100 + avgCape*0.1))
Freezing Level fallback       = siteAlt + (t / 0.0098) * 100  (se API non fornisce)
Base Lapse Rate (ProfWind)    = 0.65 + solarFactor*0.3  (se t180 non disponibile)
