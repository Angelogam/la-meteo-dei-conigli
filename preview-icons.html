📋 Come generare le icone

Ho creato lo script generate-icons.cjs che genera tutte le icone Android.

1️⃣ Installa la dipendenza

npm install sharp

2️⃣ Esegui lo script

node generate-icons.cjs

3️⃣ Sincronizza con Android

npx cap sync android

4️⃣ Builda l'APK

cd android
./gradlew assembleDebug
